# books

把英文书籍以 **.txt** 格式放进这个文件夹，然后回到软件里点「刷新」，书籍就会出现在书目列表中。

- 支持 UTF-8 编码的纯文本；带 BOM 或个别乱码字符也能打开。
- 文件名就是显示的书名，例如 `The Little Prince.txt` 会显示为 “The Little Prince”。
- 删除这里的书后，列表里也会同步消失（进度记录会保留，重新放回同名同内容的书仍可继续）。
- 仓库只提交 `test_book.txt` 这一份示例；其他书籍通过 `.gitignore` 排除，
  请自备有权使用的文本，不要把受版权保护的电子书推到公开仓库。
